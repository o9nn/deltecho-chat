## Autonomy repairs

### Governed preview-to-commit boundary

The original `ActiveInferenceExperimentScheduler.scheduleNextGoverned()` captured an eligible candidate, awaited authorization, then committed the old preparation. Source-loaded isolated fixtures reproduced capacity overflow, reset-era counter pollution, forge ID reuse committing a different hypothesis, and a falsified hypothesis reopened as testing.

The repair must revalidate scheduler generation, substantive hypothesis identity and eligibility, same-hypothesis exclusivity, capacity and refractory timing immediately before the actual forge mutation. Approval belongs to the original candidate; a changed candidate requires a new preview and authorization. A historical approval certificate must not imply that a trial was created. The new bounded last-decision commit-check receipt is methodological instrumentation, not a causal result or a calibrated probability.

This barrier does **not** make a captured ESN/energy context fresh while peers deliberate. Genuine commit-time context freshness remains a separate future contract; no claim to solve it by rereading an old object is made.

### Real online RLS/readout layout

`OnlineReservoirLearner` stores `[output × reservoir]` values, while `CognitiveReadout` consumes `[input × output]`. The live orchestrator previously passed the learner array directly into `setWeights(weights, 64, 256)`. The boundary adapter must preserve batch readout layout, actual recursive least-squares updates and real forward computation; configured dimensions must match the live readout rather than silently accepting the wrong shape.

Tests must compare the genuine readout's zero-bias nonlinear output with `tanh(learner.predict(state))` using a non-square layout, then train the actual learner and check post-sync parity. Controlled targets are test fixtures, not interaction-derived feedback or proof of improved real-world cognition.

The collapsed embodiment lens now exposes temporal provenance for the **last measured native pair**:

- actual composed-target write sequence;
- native before-model-update sequence at write and readback;
- real native callbacks since the latest write;
- one consistent monotonic write/read interval;
- retained write epoch in the feedback experience, separate from the observed epoch.

The manager updates timing together with `lastAppliedCubism`, including metabolic/resonance rewrites. It preserves the existing two-callback sampling schedule, native parameter membership filtering, residual arithmetic, calibration rate/threshold/direction and feedback events. The latest write can therefore be younger than the initial cognitive projection. Unknown or backwards monotonic timing produces unavailable metadata, not fabricated zero latency.

Manual overrides/locks, authority-window resets, unusable readback, reinitialization and disposal clear timing provenance. Snapshots are detached. The clock retains only the latest write and uses no timer, new subscription, history, persistence or neural control path. The lens's existing open/hidden/unmount gates remain in force.

**Interpretation:** this is target-write → native parameter readback, after physics and before Cubism mesh evaluation. It is not render latency, settling time, calibrated prediction horizon, pixel fidelity, causal discovery or proof of calibration improvement. Epoch clock changes do not affect the monotonic duration.
